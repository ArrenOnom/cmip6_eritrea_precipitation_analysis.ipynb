# cmip6_eritrea_precipitation_analysis.ipynb
Python notebook and datasets for evaluating 34 NEX-GDDP-CMIP6 climate models over Eritrea. Includes CHIRPS-based validation, CRI ranking, and future precipitation projections under SSP2-4.5 and SSP5-8.5 scenarios, with trend analysis, PCI, and variability assessment across agroecological zones.
